# CA Services Web App

## Overview

A multi-page Chartered Accountancy services web application designed to provide visitors with organized information about professional accounting, taxation, auditing, and business advisory services through a clean and user-friendly interface.

## Features

- **Home Page:** Introduces the CA practice and its services.
- **Services Section:** Dedicated pages for various professional services.
- **Taxation Services:** Includes GST, income tax, and NRI taxation.
- **Business Services:** Covers auditing, bookkeeping, business registration, and payment processing.
- **About Page:** Provides information about the practice.
- **Careers Page:** Displays career-related information.
- **Resources Page:** Provides useful information for visitors.
- **Contact Form:** Allows visitors to submit enquiries.
- **Database Integration:** Uses SQLite3 to store contact form submissions.
- **Database Utilities:** Includes scripts for database initialization and data export.

## Who Can Use This?

- **Chartered Accountants:** To establish an online presence and showcase professional services.
- **CA Firms:** To present their services, expertise, and business information to potential clients.
- **Accounting Professionals:** To provide visitors with an organized platform for exploring accounting and taxation services.
- **Developers:** As a reference project for learning Flask, SQLite3, and multi-page web application development.

## Getting Started

### Prerequisites
- Python 3.x
- pip (Python package installer)
- Git

### Installation

**1. Clone the repository** :
<br>
git clone YOUR_REPOSITORY_URL

**2. Navigate to the project directory** :
<br>
cd ca-services-web-app

**3. Create a virtual environment** :
<br>
python -m venv venv

**4. Activate the virtual environment** :
<br>
For Windows:
venv\Scripts\activate

**5. Install dependencies** :
<br>
pip install -r requirements.txt


**6. Run the application** :
<br>
python app.py

**7. Open the application** :
<br>
Visit:
http://127.0.0.1:5000
